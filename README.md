# ActiveHerb mockup — iteration 11

Standalone static preview of iteration 11, based on the iteration 02 website with the enlarged botanical bottle labels. The first two homepage range cards carry the requested Bestseller and Trending badges as design treatments.

Open `index.html`, or run `python3 -m http.server 8087` in this folder. No installation or build is required.

## GitHub Pages

In this repository, open **Settings → Pages → Build and deployment**:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- Click **Save**.

Preview URL after publishing: https://az0228.github.io/Activeherb-Mock/

The empty `.nojekyll` file keeps this a plain static site. All local paths support the repository subdirectory.

## Included

Homepage, catalog, product details, search, filters, variants, a browser-local demonstration bag, and the label review page (including its original-scale comparison, editable fronts, side identification panels, and review PDF).

Only iteration 11 and the assets used by its pages are packaged. PSD masters, full label wraps, unused artwork, other website iterations, and local tooling remain in the original workspace.

This is a design concept. The bag does not submit orders or collect payment. Product facts and price provenance remain as recorded in the supplied catalog. Proposed labels are visual concepts, not production packaging. Engraved illustrations are retained generated concept artwork. Font licensing is included under `assets/labels-v5/DM-Sans-OFL.txt`.
